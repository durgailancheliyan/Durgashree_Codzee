MedBookInd

Visual Page Documentation - Healthcare Management System

Technology Stack

Frontend

React 18+ with TypeScript, Tailwind CSS, Radix UI

Backend

Node.js, Express (TypeScript), REST API — project folder medbookind.server

Database

PostgreSQL (Docker Compose or local instance; schema in server src/schema.sql)

Charts

Recharts, Custom KPI Cards

Client and server architecture

The browser loads the React app from the Vite dev server (HTTPS, port 5173). All HTTP calls use relative paths under /api; Vite proxies them to the Express API (default http://localhost:5000). JWT bearer tokens are stored in localStorage and attached by Axios interceptors in src/services/*.ts.

Browser (React + TypeScript + Tailwind) → Vite dev server :5173 (HTTPS) │ proxy /api → └→ Express API :5000 (medbookind.server) └→ PostgreSQL

auth.service.ts, users.service.ts, practice.service.ts, location.service.ts, onboarding.service.ts, txconfig.service.ts

Guards

ProtectedRoute (role), PrivateRoute (auth + onboarding), AuthContext

REST API prefixes (server)

Prefix Responsibility
/api/auth Login, register, password reset, validate token
/api/user Users for a practice; roles and locations for current user
/api/practice Practice CRUD, multipart logo
/api/location Location CRUD
/api/Onboarding Onboarding data/status, bulk steps, subscription
/api/TreamentConfig Treatment categories, plans, addons (name matches legacy client path)
