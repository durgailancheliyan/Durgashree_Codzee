# MedBookInd Client (`medbookind.client`)

Vite + React + TypeScript frontend for MedBookInd.

**Full setup for client + server:** see the root [README.md](../README.md).

## Quick run

Start the API first (`medbookind.server` on port 5000), then:

```bash
npm install
npm run dev
```

- App: `https://localhost:5173` (or next free port)
- `/api` is proxied to `http://localhost:5000`

UI / page docs: [docs/README.md](./docs/README.md).
